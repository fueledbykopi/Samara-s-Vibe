# Apple Music Clone for Android 🎵



![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.1.0-red.svg)
![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)

A high-fidelity, feature-rich music player web application inspired by Apple Music's premium aesthetic. Built with Vanilla HTML, CSS, and JavaScript for maximum performance and a native feel on Android devices.

## ✨ Features

- **💎 Premium UI**: Glassmorphism effects, clean typography, and uncluttered layout.
- **🌈 Dynamic Background**: Background colors adapt in real-time to the current song's artwork.
- **📜 Interactive Lyrics**: Real-time, synced lyrics view with automatic scrolling.
- **🔼 Now Playing Drawer**: Smooth, native-like slide-up player with cubic-bezier animations.
- **📻 Explore Tabs**: Dedicated sections for Library, Browse, and Radio.
- **🔊 Advanced Controls**: Volume slider, progress seek, and full playback controls.
- **📱 Mobile Optimized**: Responsive design tailored for Android screen ratios.

## 🚀 Quick Start

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/apple-music-clone.git
   ```
2. Navigate to the project directory:
   ```bash
   cd apple-music-clone
   ```
3. Open `index.html` in your browser or use a local server:
   ```bash
   # If you have Python installed
   python3 -m http.server 8000
   ```

## 🛠️ Tech Stack

- **HTML5**: Semantic structure.
- **CSS3**: Custom properties, Flexbox/Grid, Glassmorphism, Animations.
- **JavaScript**: ES6+ Modules, State Management, DOM Manipulation.
- **Icons**: [Lucide Icons](https://lucide.dev/).
